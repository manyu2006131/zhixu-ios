# 知序 · 魔女手账

**把学习、复习和日常生活，装进一本紫色魔法手账。**

知序是一款原生 iPhone 学习与生活助手，采用伊蕾娜主题插画与紫蓝星空配色，帮助记录每天的小进步。支持 **iOS 18 及以上**。

![主题插画](Zhixu/Assets.xcassets/Witch.imageset/witch.jpg)

## 可以用它做什么

| 场景 | 功能 |
| --- | --- |
| 安排每天 | 待办、定时提醒、每日最低任务、任务拆分、考试倒计时 |
| 专心学习 | 一键开始学习、番茄钟、暂停继续、休息模式、学习进度与七天周报 |
| 记牢知识 | 间隔复习、主动回忆、错题本、英语生词卡、积压复习整理 |
| 记录生活 | 人民币记账、分类统计、月预算、攒钱进度、健身训练卡、体重与腰围 |
| 随手使用 | 系统翻译、记事本、随手收集箱、资料收藏夹、快速计算器 |
| 保存数据 | 本地保存、完整 JSON 备份与恢复、每周备份提醒 |

错题和生词保存后，会自动加入复习卡。默认复习间隔为 1、2、4、7、15、30 天；根据自测结果调整下一轮。这是学习辅助，并非个人遗忘规律的精确预测。

## 下载与安装

当前版本：**0.2.0，未签名 IPA**。

[打开已验证的构建与下载页面](https://github.com/manyu2006131/zhixu-ios/actions/runs/41064161077)

1. 登录 GitHub，打开上述页面。
2. 在 **Artifacts** 下载 `Zhixu-iPhone-4`。
3. 解压后找到 `Zhixu-unsigned.ipa`，为自己的 iPhone 完成设备签名后安装。

**IPA 需要签名，不能直接点击安装。** 当前未发布到 App Store。Actions 下载产物有保留期限；过期后可在 Actions 中查找更新的成功构建，或使用源码自行编译。目前尚未创建长期下载的 Release。

## 开始使用

- 首页点击“一键开始”进行 25 分钟专注。
- 到“工具”页开启通知权限，并使用各项小工具。
- 复习时先尝试回忆，再揭示答案，如实选择记住或忘记。
- 定期在“备份与恢复”导出数据，卸载前先备份。

## 数据与验证

数据仅保存在本机，无账号、云同步或广告；不自动读取银行账单。通知受系统权限、静音和专注模式影响。

已通过旧数据迁移、备份往返、数值边界测试、iPhone Release 编译、模拟器编译启动，以及关键工作流 UI 测试。**真机签名安装、锁屏通知、系统翻译和完整真机交互仍待验收。**

## 开发

SwiftUI 原生工程，无第三方 SDK。打开 `Zhixu.xcodeproj` 即可继续开发；`python3 scripts/prepare.py` 可重建工程，Mac 上执行 `python3 scripts/test-models.py` 可验证数据兼容性。
