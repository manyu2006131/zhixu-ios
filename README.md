# 知序 · 魔女手账 0.2

原生 SwiftUI iPhone 学习与生活助手，iOS 18+，无第三方 SDK。

保留：待办与定时提醒、人民币记账、后台番茄钟、间隔复习、系统翻译、可搜索笔记、JSON 备份恢复。

新增 16 项：学习一键开始、错题本、英语生词卡、学习进度条、每日最低任务、任务拆分器、复习积压整理、学习周报、健身训练卡、体重与腰围记录、预算与攒钱进度、随手收集箱、考试倒计时、资料收藏夹、快速计算器、数据备份提醒。

伊蕾娜主题：银白与紫蓝星空插画、主题首页与应用图标、深色阅读界面。个人主题项目，不代表官方应用。

## 使用

首页一键开始 25 分钟专注；工具页管理所有新增工具。错题和生词保存时自动加入间隔复习。首次开启通知后可接收待办、复习、专注结束与每周备份提醒。通知受系统权限、静音和专注模式影响。

Windows 用户在本仓库 Actions 的最新成功运行中下载 `Zhixu-iPhone-*`，解压得到 `Zhixu-unsigned.ipa`。此包尚未签名，需使用与个人设备匹配的签名方式后安装，无法直接点开安装。

## 开发与验证

打开 `Zhixu.xcodeproj`。`python3 scripts/prepare.py` 可重建工程文件和共享 scheme。Mac 上执行 `python3 scripts/test-models.py` 验证旧数据迁移与备份往返。Actions 执行模型测试、设备 Release 编译、IPA 打包、模拟器编译启动、截图及 UI 流程测试；查看运行结果确认是否全部通过。

应用数据仍使用原 `zhixu-v1.json`，旧版文件缺少 extras 时自动填充新工具默认值。升级前建议备份。新建安装为空白，不预填用户体重、预算或训练方案。
