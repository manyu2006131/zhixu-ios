# 知序 · iPhone 学习与生活助手

六个模块：每日待办、花销记录、番茄钟、间隔复习、系统翻译、记事本。支持本地通知及 JSON 备份恢复。

SwiftUI 原生工程，最低 iOS 18；无第三方包。工程根目录为本仓库根目录。

## Windows 用户获取 IPA

1. 打开本仓库 Actions → Build iPhone IPA。
2. 提交代码会自动编译，也可点 Run workflow 手动触发。
3. 打开完成的运行，在 Artifacts 下载 `Zhixu-iPhone-运行编号`。
4. 解压得到 `Zhixu-unsigned.ipa`、SHA256 和编译日志。

**产物为未签名 IPA，需要针对实际设备签名后安装。编译通过不代表已完成六个模块的真机验收。**

工作流执行真机架构编译、IPA 打包和模拟器编译/启动检查；翻译、锁屏通知和后台计时仍需真机测试。首次构建结果以 Actions 实际日志为准。

## 功能及限制

待办支持时间提醒；花销以整数分保存并按月分类汇总；专注保存绝对结束时间；复习默认间隔 1/2/4/7/15/30 天，从实际复习时间安排，忘记则重置；翻译使用苹果系统面板；笔记需手动点保存。

应用数据保存在本地，卸载前请通过工具页导出备份。没有云同步、登录或广告。通知需系统授权，受静音及专注模式影响，最多安排最近 60 条。

详细说明和待执行验收清单见 [使用说明与交付状态](使用说明与交付状态.md)。
